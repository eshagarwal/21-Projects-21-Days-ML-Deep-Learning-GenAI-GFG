# 🚀 21 Projects in 21 Days — ML, Deep Learning & GenAI

A structured hands-on journey through **Machine Learning, Deep Learning, and Generative AI**, completed as part of the GeeksforGeeks 21 Days Challenge.

This repository showcases **21 mini-projects**, each focused on a specific concept — ranging from data analysis and classical ML to advanced deep learning and GenAI applications.

---

## 📌 Overview

- 📅 **Duration:** 21 Days  
- 🧠 **Focus Areas:**  
  - Data Analysis & EDA  
  - Machine Learning  
  - Deep Learning  
  - Time Series  
  - Computer Vision  
  - Generative AI & LLMs  

Each day contains:
- 📓 Jupyter Notebook  
- 📊 Analysis / Model  
- 📝 Dedicated README

### 📊 Data Analysis & EDA
- Titanic Survival Analysis  
- Netflix Content Analysis

- House Price Prediction (Regression)  
- Heart Disease Prediction (Classification)  
- Customer Segmentation (Clustering)  
- Feature Engineering for Churn Prediction

- CIFAR-100 Image Classification  
- Transfer Learning (ResNet, VGG, MobileNet)

- GAN-based Image Generation

- GPT-2 Prompt Engineering  
- Text-to-SQL using LLMs  
- Intelligent Document Processing (OCR + AI)
